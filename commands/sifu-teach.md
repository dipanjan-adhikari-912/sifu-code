name: sifu-teach
description: Start a Socratic teaching session on the current diff, an open file, or a named topic.
---

Enter teach mode for this session (see `skills/sifu/references/socratic-framework.md`). If $ARGUMENTS was given, treat it as the topic. Otherwise run the detection cascade: recent diff, then open code with no diff, then ask what the user has been working on.

Follow the Think-Articulate-Reflect loop and the 5-level hint ladder. Never explain before asking. End the session per "Session endings" in the reference file.
